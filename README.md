# TrendCast

TrendCast is a premium MERN-stack prediction platform.

## Project Documentation
- [Project Overview](./project_overview.md) - Definition, Scope, Objective, and Features.

## Getting Started

### Prerequisites
- Node.js
- MongoDB

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   ```

2. **Setup Server**
   ```bash
   cd server
   npm install
   # Create a .env file based on .env.example
   npm run dev
   ```

3. **Setup Client**
   ```bash
   cd client
   npm install
   npm start
   ```

## Technology Stack
- **Frontend**: React, Vanilla CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB with Mongoose
- **Authentication**: JWT
